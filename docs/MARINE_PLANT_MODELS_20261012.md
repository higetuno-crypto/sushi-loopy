# 004 海洋食材プラント Lv.1〜4

`marine_food_plant` をBlender製の4段階へ置き換えた。演出の目安は **25% / 55% / 85% / 120%**。所有数 **1 / 5 / 10 / 25** で成長する。施設ID、価格、生産量、保存形式、寿司屋へのトラック配送は維持。

## 造形と動き

| Lv | 目安 | 主要パーツ |
| --- | --- | --- |
| 1 | 25% | 青いタンク1基、冷蔵庫、赤い小型クレーン、氷と魚の運搬箱 |
| 2 | 55% | タンク2基、大きいクレーン、ポンプ設備、出荷待ちの箱 |
| 3 | 85% | 高低差のあるタンク3基、金の帯、整備デッキ・手すり・はしご、クレーンのカウンターウェイト |
| 4 | 120% | 大型の門型クレーン、金の魚と楕円の紋章、青い飾り、金の追加帯と回転灯 |

参考画像の主役は青いタンク・銀色の配管・赤いクレーン。石の埠頭、冷蔵庫のシャッター、背面の整備扉と通風口、タンクへ戻る配管で、側面・背面からも用途が分かる構造にした。魚のマークは凹凸のあるメッシュで、画像テクスチャは使用しない。

氷と魚を積んだ箱が12秒周期でゆっくり上下する。ワイヤーの上端をクレーンに固定し、長さと中心位置を荷物の高さから計算する。バルブは小さく往復回転し、Lv.4の回転灯も動く。すべて既存の停止・Reduce Motion設定に従う。港のカメラ範囲を16から10.5へ近づけ、注視点を少し上げて、スマホで施設を読み取りやすくした。

## 再出力

Blender MCPから `scripts/build-marine-models.py` を実行する。基本形状は002・003と同じ `scripts/blender_parts.py` を使用。

```python
path = 'D:/Sushi_Loopy/scripts/build-marine-models.py'
exec(compile(open(path, encoding='utf-8').read(), path, 'exec'),
     {'__file__': path, 'LEVEL': 1, 'FINAL': True})
```

対象レベルのシーンがあれば再利用し、なければ作成する。`FINAL=True` はそのレベルの原本・GLB・4方向画像を書き出す。タンク、配管、冷蔵庫、整備通路、クレーン、紋章を分けており、調整時にも流用できる。既存の001〜003のシーン・原本は変更しない。
