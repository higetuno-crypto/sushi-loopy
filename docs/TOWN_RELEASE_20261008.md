# 箱庭版リリース記録 — 2026-10-08

承認された [箱庭企画](SUSHI_TOWN_DESIGN_20261007.md) の初回実装。公開先は既存の [Sushi Loopy](https://higetuno-crypto.github.io/sushi-loopy/)。

## 今回の実装

- 縦持ちの街を主画面にし、設備・にぎる・模様替えを下部に固定。ドラッグ、二本指の拡大、拡大縮小ボタン、お店へ戻る操作。
- 独立した地形・9施設・人物と乗り物の生成素材。施設ごとに職人・回転皿・機械アーム・水槽と荷積み・採掘・発電の灯り・月便・氷・同期の波を表示。1/5/10/25個で拡張物と大きさを変える。
- 海洋プラント初購入の6秒の出荷演出と継続配送。購入成功イベントだけから開始し、ロード・復元からは再生しない。道は配置から算出。配送は経済計算に影響しない。
- 猫・トラック・船・氷の泡への反応、常連の注文。注文は正解で秒間生産4秒分、60秒のクールダウン。間違い・放置に罰はない。
- 店名、のれんと車の色、昼/夕方/雨、ベンチ、9区画の入れ替えと直後の取り消し。写真モードと900×1200のPNG出力。
- Save v6。v1〜v5の移行、v5の初回バックアップ、Save Code、Checkpoint、周回後の自己表現の保持と前回の街の閲覧。価格・施設ID・生産式・既存の結末は維持。
- 画像以外の描画はReact/CSS/SVG。写真は稼働中のDOMの位置を使うCanvas 2D。新規依存は追加していない。描画を停止しても収益は変わらない。

## 確認

- `npm test`: 44件成功。旧保存・壊れた入力・未来版の保護・v5バックアップ・配置・注文の誤答/連打/復元・周回後の記録。
- `npm run lint`: 指摘なし。`npm run build`: 成功。従来からの崩壊用Three.js/html2canvas chunkのサイズ注意は残るが、通常プレイの初期ロードには含まれない。
- `scripts/town-check.mjs`: Chrome、Windows版WebKitで320×568 / 375×568 / 390×844 / 430×932 / 1440×960。横はみ出し、下部操作の表示、初購入、v5移行、店名/色/天気、配置と取り消し、動作停止、注文、写真ダウンロード、リロードを検証。
- `scripts/town-journey-check.mjs`: Chromeのタッチ入力で長押しの中断、ドラッグ、ピンチ。Save CodeのUI復元、初便、同期3段階、最後の一貫、初期化後の店名保持と前回の9施設を確認。
- テストは新しい隔離ブラウザcontextだけを使う。既存プレイヤーの保存領域には触れない。
- 参考シミュレーション: 最初100秒だけ1クリック/秒、以降は効率順に自動購入する従来モデルで職人10秒、回転寿司76秒、自動握り器167秒、海洋プラント321秒。人間のプレイ測定ではなく、価格変更の根拠として使っていない。

## 再実行

開発サーバーを5180で開始し、`node scripts/town-check.mjs` と `node scripts/town-journey-check.mjs` を実行。Playwrightは既存のマシン環境を使い、別環境では `PLAYWRIGHT_MODULE` を設定する。`SUSHI_TEST_URL` で公開先、`SUSHI_ARTIFACT_DIR` で記録先を変更できる。`SUSHI_ENGINE=webkit` で基本検証をWebKitに切り替える。

## 残る評価と範囲

実機iPhone/Androidでの長時間動作、発熱、写真保存先のOS動作、継続率の評価は未実施。Windows WebKitを実機Safariの合格とは呼ばない。App Storeへの提出・ネイティブアプリ化は今回の実装範囲外。企画の24案すべてや追加の周回コンテンツは実装していない。

写真はUIを除いた記念絵として出力し、街の位置と姿を残す。CSSの光や一時的な小演出を画面と完全一致で写すスクリーンショットではない。外部へ自動アップロードしない。

小型画面の下部操作が切れる不具合、旧CSSの余白干渉、WebKitで写真の画像が抜ける不具合を検証中に修正した。
