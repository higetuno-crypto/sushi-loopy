# 幼児プレイテスト反映（2026-09-11）

4歳児が2〜3分楽しめた一方、2〜3歳児には操作が難しく、文字選択や誤操作で遊びが止まったというフィードバックを反映。

- メイン寿司／モバイル固定ボタン：押した瞬間に1回、以降250msごとに1回。離す・pointercancel・capture消失・ウィンドウ非アクティブ・非表示・アンマウント時に停止。キーボード操作も維持。
- プレイ画面の文字選択とiOS長押しメニューをCSSで抑制。寿司ボタンはtouch-action:noneとcontextmenu抑制。セーブ欄は文字選択可能。ブラウザ自身の戻る操作やOSジェスチャーまで無効にするものではない。
- 握ると寿司＋皿が飛び出して落下。表示数を制限し無制限にDOMを蓄積しない。
- 施設購入成功時にチャイム（既存の「音をつける」有効時）と「ふえた！」。購入失敗やセーブ復元では購入音を鳴らさない。
- 所有施設が並ぶ「わたしの寿司箱」。種類ごと最大3アイコン＋実際の所有数。保存データから表示し新しい保存項目は追加しない。
- 回転寿司購入後だけレーン開始。12皿＝同じ6皿を2組、幅を修正しtranslate3dでループ。
- 「核融合」を「寿司融合発電」に変更。説明と新聞も変更。施設ID・価格・保存形式は維持。

## 検証

- npm run build / npm run lint：成功（警告なし）
- npm test：29件成功（セーブ移行、オフライン、チェックポイントを含む）
- node scripts/browser-check.mjs：既存ブラウザ13項目成功
- node scripts/child-playtest-check.mjs：タッチ単発、長押し間隔、停止、キーボード、購入表示、レーン開始条件と実際のtransform変化、モバイル固定ボタン、文字選択CSS、横はみ出しなし、エラーなしを検証
- 検証ブラウザ：Windows Edge、スマホ寸法／タッチエミュレーション。実ユーザーの保存データには触れず独立ブラウザコンテキストで実施。
- iPhone実機Safari／Telegram：未確認。既存CSSのprefers-reduced-motionでレーンが停止するため原因候補。設定は尊重し、施設と営業状態は静止状態でも表示。

## 次の実機プレイで確認すること

長押しで握れるか、指を離して止まるか、文字選択やメニューが出ないか、回転寿司購入後にレーンが動くか。「音をつける」後に施設購入の音が聞こえるか。視差効果を減らす設定が有効な場合はレーン停止が仕様。

## Safari向け追加対応

ゲーム内にアニメーションの再生／停止と「端末設定に戻す」を追加。端末の動きを減らす設定を初期値として尊重し、明示的に再生を選んだ場合はレーンとタップ演出を再生する。選択はゲームのセーブとは別に保存。

`node scripts/motion-check.mjs`：Edgeのモバイルエミュレーションで、動きを減らす条件から再生、実際の移動、タップ演出、再読み込みでの選択保持、停止、端末設定への復帰を確認。Safari実機は未確認。
