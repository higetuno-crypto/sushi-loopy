# 008 鮮度凍結装置 Lv.1〜4

`freshness_freezer` をBlender製の4段階に置き換えた。成長の目安は **25% / 55% / 85% / 120%**、所有数 **1 / 5 / 10 / 25** で切り替わる。施設ID、価格、生産量、保存形式は維持する。

## 成長と遊び心

| Lv | 主な構成 |
| --- | --- |
| 1 | 小さな観察室、立体の魚、片側冷却管、雪の結晶を付けた圧縮機、操作盤、氷の箱 |
| 2 | 大きい観察室と魚、金の縁取り、左右の冷却管、冷媒タンク、背面点検ハッチ |
| 3 | さらに大きい観察室、放熱フィン、高い冷媒タンク、背面の整備通路とはしご、前面の足場 |
| 4 | 6本の氷の結晶を載せた冠、金の放熱フィン、大きな回転する雪の結晶と金の枠、左右の氷の塔 |

参考画像の青い円筒・魚・雪の結晶・配管を残し、前面が開いた観察室にした。氷色の背面と側面は不透明な立体形状で、透明面の描画順に依存せず魚が見える。魚には白い腹、両側の立体の目、ひれ、別可動の尾びれがある。上部の圧縮機は横梁で支える。

魚はゆっくり上下して向きを変え、尾びれを振る。冷却ファンとLv.4の雪の結晶が回り、冷却面が穏やかに発光する。既存のアニメーション停止・Reduce Motion設定に従う。

## 再出力と拡張

Blender MCPから次を実行する。`LEVEL` を1〜4に変更できる。

```python
path = 'D:/Sushi_Loopy/scripts/build-freezer-models.py'
exec(compile(open(path, encoding='utf-8').read(), path, 'exec'),
     {'__file__': path, 'LEVEL': 1, 'FINAL': True})
```

対象シーンがあれば再利用し、なければ作成する。`FINAL=True` で原本・GLB・4方向画像を保存。土台、観察室、魚、冷却配管、操作盤、整備通路、冠を分けて編集できる。基本形状には既存の `scripts/blender_parts.py` を使用する。各レベルは同じ土台と魚の可動構造を使い、冷媒タンク・整備通路・冠を順に追加する。
