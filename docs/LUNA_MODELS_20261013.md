# 007 LUNA_SEA Lv.1〜4

`luna_sea` をBlender製の4段階に置き換えた。成長の目安は **25% / 55% / 85% / 120%**、所有数 **1 / 5 / 10 / 25** で切り替わる。施設ID、価格、生産量、保存形式は維持する。

## 成長と遊び心

| Lv | 主な構成 |
| --- | --- |
| 1 | 赤白のロケット、紺の発射架、海色の観測ドーム、月を追うアンテナ |
| 2 | 長い機体と発射架、2基の燃料タンク、発射台への供給管 |
| 3 | 左右の補助ブースター、金の補強材と手すり、大きな観測ドーム、寿司の宇宙便 |
| 4 | 右側の柱に直接載せた金の月章、赤と金の補助ブースター、金のドーム枠、大型機体 |

参考画像の赤白ロケット・発射架・青いドームを主役にした。背面には整備用はしご、ドームの点検扉、タンク配管を配置。月と海の紋章、ドームの枠、機体の帯は立体形状。Lv.3以降は輸送庫に小さなサーモン寿司を載せた。

24秒周期の最後に短い浮上試験を行い、同じ発射台へ滑らかに戻る。ロケットは消失せず、噴射炎は台を貫通しない長さに制限。アンテナもゆっくり回る。既存の停止・Reduce Motion設定に従う。

## 再出力と拡張

Blender MCPから次を実行する。`LEVEL` を1〜4に変更できる。

```python
path = 'D:/Sushi_Loopy/scripts/build-luna-models.py'
exec(compile(open(path, encoding='utf-8').read(), path, 'exec'),
     {'__file__': path, 'LEVEL': 1, 'FINAL': True})
```

対象シーンがあれば再利用し、なければ作成する。`FINAL=True` で原本・GLB・4方向画像を保存。土台、発射台、機体、発射架、はしご、観測棟、ドーム、アンテナ、燃料設備、外周設備、月章付きの柱を分けて編集できる。基本形状には既存の `scripts/blender_parts.py` を使用する。発射台の中心を固定したまま機体の高さ・補助ブースター・背面設備を段階的に拡張した。
