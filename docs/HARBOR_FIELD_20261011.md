# 海辺の建築フィールド — 2026-10-11

四角い台座を、岬のある本島と木橋でつながる小島に置き換えたテスト実装。海岸の段差、浅瀬、砂浜、岩、港の桟橋、灯台、桜で場所を見分けられるようにする。既存のThree.jsと図形を再利用し、追加ライブラリ・画像テクスチャは使わない。

## 配置と表示

- `src/game/rendering/townField.ts` に海岸線、9区画、道路、橋をまとめる。区画は保存済みの0〜8を維持し、施設の種類とは独立する。
- 建物が立つ面は高さ0で統一。高低差は海岸・砂浜・浅瀬で表現し、建物が浮いたり、移設時に段差へ食い込んだりしない構成。
- 土地と道路は材質別の静的メッシュに結合。異なる形状のindex有無を揃えてから結合することで、全施設表示時に金色パーツなどが消える問題も修正。
- 配達経路は描画に使う道路の接続情報から作る。小島へ店またはプラントを移しても橋を通る。曲がり角は短い曲線でつなぐ。
- 「お店」「港」「全景」、設備購入、模様替え、写真、動き停止、終盤のUI破砕を維持。全景は島と橋が収まる画角に調整。
- 価格・生産量・施設ID・Save v6は変更しない。保存は区画IDなので、既存データの移行は不要。以前の街も現在の地形上に配置される。

## 検証

`tests/town-field.test.mjs` は9区画の建物範囲が陸上に収まること、道路と重ならないこと、橋以外の道路幅が地面に支えられること、72通りの配達で車輪が道を外れないことを検査する。初回に検出した道路の食い込みと海上へのはみ出しを修正済み。

`scripts/town-check.mjs` はChrome / Windows WebKitで320×568、390×844、1280×720の表示・購入・保存・模様替え・取り消し・写真・動き停止・崩壊を検証。console.errorも失敗として扱う。全9施設表示と、小島への引っ越し後の橋上配達の検査を追加。

```powershell
npm test
npm run lint
npm run build
$env:SUSHI_ARTIFACT_DIR='artifacts/harbor-field/final-chrome'
node scripts/town-check.mjs
```

初期47テスト、lint、buildを通過。確認画像とブラウザ結果は `artifacts/harbor-field/`。実機iPhoneの発熱・長時間フレームレートは未測定。建物のLv.0〜4 Blender/GLBは保存したままで、今回は既存のゲーム内建物を使って地形を検証する。

本体への変更は描画ファイルと検査だけ。地形を戻す場合はこの機能のコミットをrevertする。保存データは同じ区画IDのまま使える。
