# 立体の街とスクロールUI — 2026-10-09

実機写真で確認された、街の画面外への移動、文字の常駐、画像の部分揺れ、画面内への詰め込みを修正する。[前回の実装記録](TOWN_RELEASE_20261008.md)を置き換える変更。

## 変更

- 街は既存のThree.jsで実際の立体形状を描画。屋根・建物は静止し、職人の腕、皿、機械、車輪などを個別に動かす。外部の3Dモデルや新しい依存は追加していない。
- 固定された「お店・港・全景」の構図。ドラッグはページの縦スクロールに使い、島を画面外に投げ出すパン操作を削除した。購入時は対象施設へ寄る。
- 高さ100svhの固定グリッドを廃止。街の下に操作、新聞、設備が続く。設備の閲覧中は既存の握るドックを使う。
- 常連の吹き出し、会話選択の画面、購入を文章で実況する演出を削除。猫の尻尾、職人の腕、運転手の手、船の旗で反応する。注文の既存保存フィールドは保持。
- 配達は道上の積載待機・往路・荷下ろし・復路の周期。配置変更にも追随。街のアニメーションは生産計算を変更しない。
- 静止部品を材質ごとに結合、DPR上限1.75、画面外と非表示タブでは描画停止。動きを抑える設定に対応。崩壊中は現在の構図で停止して、従来のUI破砕に画面を渡す。
- 写真はWebGLの描画そのものをPNGへ保存。縦長の画角でも島の横幅を確保。WebGLを失った場合は街だけ再表示でき、設備・保存の操作は続く。
- 価格・生産・施設ID・Save v6・旧保存移行・周回記録を維持。
